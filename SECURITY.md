# FIZZAROLLIO — отчёт по безопасности

Дата: 2026-11-20. Область: index.html (GitHub Pages) и проект Supabase gqpiiioyhwscbxivufre.
Не является гарантией «100% безопасности»: клиентский код публичен по определению.

## Что проверено реально (SQL на проекте)
- Неверный пароль → BAD_PASSWORD, 13-я попытка → RATE_LIMIT; верный пароль в любом регистре возвращает текст.
- file_bonus без верного пароля отказывает; get_clue(9) → NOT_FOUND; verify_card на несуществующий номер → found:false.
- У anon нет прав ни на одну таблицу; у authenticated только SELECT на cards. Storage-бакетов нет.
- claim_card: выдача только подтверждённому email, один email — одна карточка (включая алиасы), повтор возвращает ту же (проверено ранее на тестовых пользователях, затем удалены).
- security advisors: остались только намеренные предупреждения (публичные RPC).

## НЕ проверено
- Работа сайта в браузере и на iPhone после правок.
- Edge Functions (доступ к списку не был разрешён).
- История Git (в архиве нет .git): выполни `git log -p -S service_role` и `gitleaks detect`.
- Определение IP клиента внутри базы: используется заголовок cf-connecting-ip, не подтверждён. Если заголовка нет, действует ослабленный общий лимит (x20).
- Реальная отправка и доставка писем (см. docs/AUTH_SETUP.md).

## Ограничения GitHub Pages
HTTP-заголовки (HSTS, X-Frame-Options, Permissions-Policy, frame-ancestors) через HTML недоступны. HSTS даёт GitHub Pages сам. Файл _headers работает на Netlify/Cloudflare Pages. Минификация/обфускация не добавлена: защиты не даёт, но может сломать сайт.

## Секреты
В коде только sb_publishable_... (публичный). service_role и secret keys в проекте не найдены. Менять нечего, если ты не публиковал их в других местах; legacy-ключи отключи.
